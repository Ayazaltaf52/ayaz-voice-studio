🎙️ Ayaz AI Voice Studio

Ayaz AI Voice Studio is a state-of-the-art, web-based voice synthesis platform leveraging Google's Gemini 1.5 Flash architecture. Designed for creators, narrators, and developers, it offers professional-grade text-to-speech capabilities with granular control over prosody, pitch, and speed.

✨ Key Features

Unlimited Voice Generation: Process extensive scripts (up to 25k+ words) with smart auto-chunking technology.

Instant Voice Cloning: Upload reference audio samples to train custom voice models in seconds.

Smart Human Mode: Proprietary algorithm that injects natural pauses, breathing patterns, and emotional intonation.

Pro Audio Effects: Real-time DSP effects including Reverb, Echo, Radio, and 8-Bit Lo-Fi.

Granular Controls: Fine-tune pitch (-20 to +20) and playback speed (0.5x to 2.0x) for perfect delivery.

History & Library: Local storage integration to save and manage generated audio artifacts.

🛠️ Technology Stack

Core Engine: React.js (v18)

Styling: Tailwind CSS

Audio Processing: Web Audio API & OfflineAudioContext

AI Backend: Google Gemini API (REST)

Icons: Lucide React

🚀 Getting Started

Clone the repository.

Install dependencies using npm install.

Run the development server with npm run dev.

Build for production using npm run build.
